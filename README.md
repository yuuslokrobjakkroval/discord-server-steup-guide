# Discord Server Essentials

Next.js App Router, TypeScript, Tailwind CSS, and locally owned shadcn/ui Button (Radix Slot + CVA).

Run `npm install`, then `npm run dev`. Open http://localhost:3000. Production: `npm run build` then `npm start`. Run `npm run typecheck` to check TypeScript.

The library presents 289 downloadable files in category tabs, with individual downloads, category ZIPs, and a complete ZIP. The 20 preview sheets are excluded from downloadable listings and ZIP bundles; original source copies remain untouched. Typography uses self-hosted Poppins with its included OFL license. PDF content is also readable in the website. Checklist progress is stored only in the current browser. No account or database is needed.

IMPORTANT: The original READ ME prohibits redistributing these assets as-is or uploading them to other sites. This project is for local/private review. Obtain permission from Ethical Studio before publishing the bundled resources. Original attribution and font licenses are retained. The Role Icons folder mentioned in the PDF was not supplied.

Original files remain untouched outside this project. Resource manifests are in lib/resources.json and lib/guides.json; downloadable copies are in public/files and public/bundles.

Release and deployment automation: see [.github/SETUP.md](.github/SETUP.md) for branch behavior, automatic versions, and GitHub/Vercel secrets.

The Fonts tab includes live editable previews, Clean/Gaming/Headline filters, individual TTF and license downloads, and the font guide. Font ZIPs include all supplied static weights and licenses.

Resource directories use descriptive names with hyphens instead of spaces and without numeric prefixes (for example, `public/files/Fonts` and `public/files/Emojis/Bullets`). The manifests and ZIP entries use the same paths.
